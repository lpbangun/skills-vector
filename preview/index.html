Retrieve a cited finding and a release-pinned chart

From get_occupation, take a returned claim_id, component_refs[].component_id, and release_id. Call get_claim for the stored finding and get_component with the component id and release pin. HTTP reads are /api/claim?id=…&release=… and /api/component?id=…&release=….

Component references copy as component_id@release_id. Their stable ids include role, measure, and definition version; always keep the release id with the reference. The component exposes raw numerator/denominator counts, dates, calculation, underlying observations, original source links, unknowns, and limitations.

Use the returned citation URL for claims and original source URLs for evidence. A newer release does not update an old pinned component. Unknown is not evidence of absence.
