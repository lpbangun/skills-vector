# Role Atlas local fonts

Self-hosted original TTF files for the reference typography: IBM Plex Sans 400/500/600,
IBM Plex Mono 400/500 and STIX Two Text 500/600. Retrieved from the public Google Fonts
CSS endpoint (the same families/weights as design-concepts/role-atlas.html) and its
fonts.gstatic.com URLs. The SIL Open Font License notices are included per family,
from https://github.com/google/fonts/tree/main/ofl (ibmplexsans, ibmplexmono,
stixtwotext). Fonts are unmodified. No external font request is made at runtime or
in tests; fonts.css points exclusively to these local assets.
