   - **How it judges a posting:** the origin plus its ownership note is the employer identity. The posting is admitted whatever the hiring organization says, including when it is missing.

   - **What is reported:** the capture and the probe report counts per distinct `hiring_entity`, so the reviewer can audit them.
   - **When it still rejects:** if the normalized entity equals another roster employer's name or alias, the posting is rejected as `organization_other_roster_employer`.
   - **Tests:** one fixture per case: a Workday entity name admitted, a missing name admitted, another roster employer rejected, and the rule on a non-Workday host without a note rejected.
