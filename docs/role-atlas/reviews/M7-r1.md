     - "Enterprise Account Executive, Growth" (5);

   Fix:
   - **Discriminating evidence only.** A level rule must name scope that separates levels. Duties common across the ladder (full cycle, quota, pipeline, CRM hygiene, prospecting) never assign a level. Add a test that the quote above assigns nothing on its own.

     - SMB / Commercial / Velocity / Select → L2;
     - Mid-Market / Territory → L3;
     - Enterprise / Corporate / State Enterprise / Public Sector named-account → L4;
     - Strategic / Named / Global / Key → L5.

     Seniority words ("Senior", "Sr.", "II", "Lead") and years stay weak. Segment beats generic duties. Two different segments in strong evidence count as a conflict and stay unassigned.
   - Record this rule in the role's ladder evidence. Put the segment-to-level table in a checked-in mapping file with a rationale per row, so it is auditable and role-specific. Other roles get no title-based scope unless a similar reviewed table exists.
